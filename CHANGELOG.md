## [0.6.0](https://github.com/PiwiTests/platform/compare/v0.5.0...v0.6.0) (2026-07-02)

### Features

* **MCP server expanded from 14 to 38 tools** — global search, run insights, spec health, slow tests, performance & stability trends, network requests, failure groups, repo commits & diffs, test catalog, traces, tags, links, recent activity, instance stats
* AI failure-cluster workflow via MCP — list open clusters, diagnose, explain failures, set status & base commit, submit feedback
* locator healing exposed through MCP with enriched healing context
* timeline span-type filter — data-driven toggles for tests, setup, hooks, fixtures & wasted waits
* OpenAPI spec generated at build time and served at `/_openapi.json` in production

### Improvements

* full reporter refactor with a modular internal architecture and new architecture docs
* improved AI context building: data aggregation, error fingerprinting, source snippets, trace parsing
* MCP hardening from an external API audit: pagination cursors, enforced project scope, richer flaky stats
* timeline fixes (wasted-time bars persisting), more data on test-case pages, more realistic demo seed

## [0.5.0](https://github.com/PiwiTests/platform/compare/v0.4.4...v0.5.0) (2026-06-28)

### Features

* locator healing: capture & suggestion of alternative locators, signature-based matching, convention-preserving fix recommendation
* backend logs shown under each network request in the test-case view
* home page revamp with filtering by environment and run type; settings revamp with env-var info
* test screenshots sent to AI diagnosis and embedded in HTML export
* user display names and optional passwords; demo "act as" user switcher
* **reporter:** heartbeat for fast interrupted-run detection

### Improvements & fixes

* diagnosis streaming and evidence-quality improvements; improved failure-cluster page
* run insights UX with baseline detection and empty states
* Docker image optimization and Docker Hub repository update
* fixed 404 redirect logic and test-case grid counts
